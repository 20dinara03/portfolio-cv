# Portfolio CV — Dinara Garipova

HR-focused portfolio site built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Sections

- **Hero** — role, availability, quick stats
- **About** — summary for recruiters
- **Skills** — frontend, full-stack, mobile
- **Work** — 6 live production projects (Spinny, Cantexniki, Moonera, Paradim, DOORS RUSSIA, Kuptsov Realty)
- **Projects** — top 5 VUT FIT GitHub repos
- **Education** — MSc/BSc at FIT VUT Brno
- **Contact** — email, LinkedIn, GitHub

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Recommended: **Vercel** (connect repo) or replace `20dinara03.github.io` with static export.

For GitHub Pages static export, add to `next.config.ts`:

```ts
output: "export",
```

Then `npm run build` and deploy the `out/` folder.
